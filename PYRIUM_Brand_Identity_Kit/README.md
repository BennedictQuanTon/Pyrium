# PYRIUM Brand Identity Kit

A reusable package of PYRIUM identity assets for web, frontend, presentations, and app surfaces.

## Contents
- `01-logos/`: primary SVG, vector trace, transparent PNGs, white-background and reversed variants.
- `02-icons/brand/`: mark-only raster exports and vector trace source.
- `02-icons/ui/`: minimal UI SVG icons.
- `03-app-and-favicon/`: app icon sizes and favicon files.
- `04-brand-guidelines/`: palette, typography, logo-use guidance.
- `05-frontend/`: React component, CSS tokens, Tailwind theme example.

## Recommended use
- Website header: transparent primary logo, typically 180–280 px wide.
- Dark hero/footer: reversed logo on a `#111111` surface.
- Favicon/social avatar: mark-only icon.
- Product UI: brand red for primary actions, black for primary text, graphite for secondary text.

## Fidelity
The exact SVG uses embedded raster artwork to preserve the provided logo's appearance. The vector trace is editable but is not guaranteed to be mathematically identical to the raster reference. Use the exact artwork for maximum visual match and refine the vector trace before print/manufacturing if required.

## Font
Inter Display / Inter. No JetBrains Mono is used as the brand typeface.

## Colors
Black `#111111`; Signal Red `#D9292F`; White `#FFFFFF`; Graphite `#8A8A8A`; Mist `#F3F3F3`.
